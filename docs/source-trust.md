# Source Trust

Trust é separado de confiança, Technical Match, prioridade, elegibilidade e completude documental.

| Tier | Origem típica |
|---|---|
| A | ATS estruturado ou carreira oficial |
| B | job board conhecido |
| C | Public Web, blog/news ou formulário com proveniência |
| D | sinal social, recrutador, comunidade ou captura manual |
| E | origem desconhecida/inconsistente |

Em conflito estruturado, ATS oficial vence, mas a alegação comunitária permanece na proveniência. Similaridade incerta vira “possible duplicate”, não merge agressivo.
