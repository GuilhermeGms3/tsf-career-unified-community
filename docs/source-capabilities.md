# Capabilities verificadas das fontes

Discovery verificado em **15/09/2026** e superfície de candidatura atualizada em **03/10/2026**, usando documentação oficial ou o portal oficial quando o fornecedor não publica uma API de discovery. `Application/fill` abaixo descreve apenas o que está comprovadamente implementado no Career Unified; o runtime de `Controlled submit` continua desabilitado por padrão.

| Fonte | Pública | Autenticada | Identidade | Credencial | Application/fill no Hub | API/agregador | Limitações e fonte oficial |
|---|---|---|---|---|---|---|---|
| JobSpy (Indeed/LinkedIn/Glassdoor/Google) | Busca ampla parcial | Não | termos/local | não | não | agregador local | sujeito a bloqueio/rate limit; Glassdoor está degradado por 403 e rejeição de localização brasileira na homologação de 2026-09-16. [Projeto oficial](https://github.com/speedyapply/JobSpy) |
| Greenhouse | por empresa | POST privado existe | board token | não para GET | fill e Controlled Submit com gates | API pública | não é busca global; envio exige runtime e preflight fresh. [Job Board API](https://developers.greenhouse.io/job-board.html) |
| Lever | por empresa | candidatura autenticada/rate-limited | site/slug | não para postings | fill e Controlled Submit com gates | API pública | não há full-text global; envio exige runtime e preflight fresh. [Postings API](https://github.com/lever/postings-api) |
| Ashby | por empresa | APIs privadas separadas | jobs page | não para postings | schema/upload/fill e Controlled Submit limitado | API pública | discovery por board; envio exige runtime, consentimento e revalidação fresh. [Public Job Posting API](https://developers.ashbyhq.com/docs/public-job-posting-api) e [careers page](https://developers.ashbyhq.com/docs/creating-a-custom-careers-page) |
| SmartRecruiters | por empresa | APIs privadas separadas | company identifier | não para postings | fill e Controlled Submit com gates | API pública | sem discovery global; envio exige runtime, consentimento e revalidação fresh. [Application API](https://developers.smartrecruiters.com/docs/application-api) |
| Workable | por subdomínio, parcial | SPI | subdomínio | token para SPI | fill e Controlled Submit com gates | API pública limitada + SPI | envio hospedado exige runtime, consentimento e revalidação fresh. [Application form](https://workable.readme.io/reference/jobsshortcodeapplication_form) |
| Workday | indireta, por tenant | APIs empresariais separadas | tenant/career site | sessão pode ser exigida | preenchimento assistido por etapa; submit manual | career site externa configurável | Candidate Home, questionários e etapas variam por tenant. [Career Sites](https://doc.workday.com/workday-education/en-us/course-manuals/recruiting-for-administrators/career-sites.html) |
| Gupy | reconhecimento de URL apenas | API empresarial | organização contratante | necessária | não implementado | API oficial autenticada | não existe adapter público/global comprovado nesta versão. [Gupy Developers](https://developers.gupy.io/) e [Find jobs](https://developers.gupy.io/reference/findjobs) |
| Vagas.com.br | não no Hub | feed/API contratada | conta empresarial | necessária | não implementado | integração oficial | ativação pelo suporte. [Vagas for Business](https://ajuda-forbusiness.vagas.com.br/portal/pt-br/kb/articles/apis-e-integracoes-vagas-for-business) |
| Catho | não no Hub | sim | empresa/integrador | necessária | não implementado | API oficial | não tratada como API pública de candidato. [Portal de desenvolvedores](https://desenvolvedores.catho.com.br/developers-integration-portal) |
| InfoJobs/Pandapé | não no Hub | integração mediante conta | conta empresarial | necessária | não implementado | API sob contratação | orientação pelo responsável da conta. [Suporte oficial](https://supportcenter.infojobs.com.br/hc/pt-br/articles/41245648835601-Posso-integrar-o-Pandap%C3%A9-com-outras-ferramentas-e-aplicativos-que-utilizo-em-minha-empresa) |
| ProgramaThor | portal público manual | não localizada | — | — | fill assistido; submit manual | sem API oficial localizada | disponível manualmente/agregadores. [Portal oficial](https://programathor.com.br/) |
| GeekHunter | portal público manual | não localizada | — | — | fill assistido quando chega por URL; submit manual | sem API oficial localizada | disponível manualmente/agregadores. [Portal oficial](https://www.geekhunter.com.br/) |
| Remotar | busca global pública | não necessária | ID estável da vaga | sim | roteia ao ATS externo; fallback assistido/manual | endpoint público operacional usado pelo portal | catálogo remoto com requisitos, empresa, modalidade e datas; sem contrato público de developer API. [Portal](https://remotar.com.br/), [catálogo](https://api.remotar.com.br/jobs?page=1&active=true) |
| Nerdin | busca global pública | não necessária | ID estável da vaga | não | roteia ao ATS externo ou usa Controlled Submit nativo | sitemap público + JobPosting + formulário público | clique final depende de preflight fresh, respostas confirmadas, currículo exato, consentimento e recibo. [Vagas](https://www.nerdin.com.br/vagas), [sitemap](https://www.nerdin.com.br/sitemap.xml) |

Alertas são uma capacidade interna transversal: EventBus/outbox do Hub, webhook n8n e Evolution. Eles não tornam uma fonte capaz de preencher ou enviar candidatura.
