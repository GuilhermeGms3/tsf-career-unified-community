# Métodos de candidatura

Toda vaga pode registrar um método explicável:

| Método | Significado |
|---|---|
| `ATS` | URL de um ATS reconhecido |
| `EMAIL` | instrução pública e contextual para enviar currículo |
| `WHATSAPP` | contato público e contextual de candidatura por WhatsApp |
| `DIRECT_MESSAGE` | candidatura explicitamente instruída por mensagem direta; execução sempre humana |
| `EXTERNAL_FORM` | formulário externo reconhecido |
| `CAREER_PAGE` | página pública de carreira |
| `MANUAL` | existe sinal, mas requer decisão humana |
| `UNKNOWN` | evidência insuficiente |

E-mail e WhatsApp somente são aceitos próximos de expressões como “envie seu currículo”, “candidaturas”, “currículo” ou “recrutamento”. Contatos gerais ou ambíguos ficam `MANUAL`, sem identificador reutilizável. Quando comprovado, persistem contato explícito, instruções, sugestão de assunto, URL e evidência. `DIRECT_MESSAGE` registra apenas o método e a origem pública. Não existe envio automático; a vaga segue normalmente por match, prioridade e seleção de currículo.
